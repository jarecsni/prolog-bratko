# Clocksin & Mellish — *Programming in Prolog*

Run in parallel with Bratko, not after it. The two cover the same opening ground —
facts, rules, questions, backtracking — from different angles: Bratko builds toward
AI programs, Clocksin & Mellish toward the language itself and its standard.
Reading them side by side turns each chapter into a second pass over the same idea,
which is the point.

Conventions — naming, the four-artifact set, how to run tests — live in the
[study README](../../README.md) and are not restated here.
