# Sterling & Shapiro — *The Art of Prolog*

Read alongside Bratko, not after it. Where Bratko teaches Prolog as a language you can
get work done in, Sterling & Shapiro teach it as logic programming — the theory first,
the language as its consequence. The two disagree often enough to be worth holding
in the head at once.

Conventions — naming, the four-artifact set, how to run tests — live in the
[study README](../../README.md).
