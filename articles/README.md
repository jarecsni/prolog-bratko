# Articles

The missing didactic layer. Written forward, not book-bound.

## What belongs here

The test: **if removing any one book from the shelf would leave the piece intact, it's an
article. If not, it's a `notes.md`.**

Two kinds live here, and they're written differently:

**Aggregations** — living documents that grow one entry per section, forever. Three of the
four headings in [`templates/notes.md`](../templates/notes.md) produce an observation every
single section — *Logic vs Control*, *Trap I fell into*, *Names for the pattern* — and
nothing else in the layout ever collects them. These files are that sink. They're worth
almost nothing at entry #1 and a great deal at entry #30, so the discipline is to keep
adding even when a single entry looks trivial.

**Essays** — standalone, finished, cross-book. Written once, revised when a later book
proves them wrong.

Planned, deliberately not created until they have something in them — the same
no-empty-scaffolding rule the section folders follow:

- `logic-vs-control.md` — where control leaks into logic, consolidated into a theory.
- `traps.md` — the wrong first clauses, catalogued. Patterns across traps teach more
  than any single trap.
- `lexicon.md` — own vocabulary, defined once.
- `swi-vs-iso.md` — where SWI departs from the standard, accumulated from real surprises.
